# Спецификация изображений

Пока реальных фото нет, на их месте — фирменные заглушки (компонент `SmartImage`)
с подписью и рекомендованным размером. Как только вы загрузите изображение нужного
**соотношения сторон** через админку (или подставите URL), оно встанет ровно на место
заглушки без изменения вёрстки.

> Все загружаемые изображения автоматически конвертируются в **WebP** (качество 82,
> ограничение ширины 2000px) — для скорости. Грузите исходники максимального качества.

## Таблица размеров

| Где используется | Соотношение | Рекомендуемый размер (px) | Поле / загрузка |
|---|---|---|---|
| **Логотип** (шапка) | ~4:1 | 512×128, PNG/SVG, прозрачный фон | `public/logo.svg` |
| **Иконка/favicon** | 1:1 | 512×512 | `src/app/favicon.ico` |
| **Главный баннер (Hero)** | 16:9 | 1600×900 | Баннеры → placement `HERO` (1-й) |
| **Второй баннер (Hero)** | 4:5 | 800×1000 | Баннеры → placement `HERO` (2-й) |
| **Баннер-мобильный** (для любого) | 4:5 | 800×1000 | поле «Мобильное изображение» |
| **Промо-полоса** | 21:9 | 1680×720 | Баннеры → `HOME_STRIP` |
| **Карточка товара / галерея** | 1:1 | **1000×1000** | Товар → Фотографии (можно несколько) |
| **Обложка категории** | 4:3 | 1200×900 | Категория → Изображение |
| **Обложка статьи** | 16:9 | 1200×675 | Материал → Обложка |
| **Фото на странице «О компании»** | 4:3 | 1200×900 | (заглушки в коде) |
| **OG-картинка по умолчанию** (соцсети) | 1.91:1 | 1200×630 | Настройки → SEO → OG |

## Как присылать изображения

Когда генерируете в ChatGPT — просите ровно в нужном соотношении сторон, например:

- *«Сгенерируй фото упаковки БАД, белый фон, квадрат 1:1, 1000×1000»* — для товара.
- *«Баннер 16:9, 1600×900, зелёная природная палитра»* — для Hero.

Затем загрузите файл в соответствующем разделе админки — он подставится автоматически.

## Стиль изображений (под бренд)
- Светлый/белый фон, много воздуха (в духе ВкусВилл).
- Натуральные акценты: зелень, травы, мёд, природные текстуры.
- Товары — по центру, мягкая тень, без агрессивных фонов.
- Единый стиль освещения по всему каталогу.
