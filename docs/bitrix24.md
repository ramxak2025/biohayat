# Интеграция с Битрикс24

Заявки с сайта создаются **лидами** в CRM Битрикс24. Дополнительно поддерживается
виджет **онлайн-чата** (Открытые линии).

## 1. Заявки → лиды (входящий вебхук)

### Создать вебхук в Битрикс24
1. Войдите в свой портал Битрикс24.
2. **Разработчикам** → **Другое** → **Входящий вебхук**.
3. Отметьте права доступа: **CRM** (`crm`).
4. Скопируйте URL вида:
   `https://ВАШ-ПОРТАЛ.bitrix24.ru/rest/1/xxxxxxxxxxxxxxxx/`

### Подключить на сайте
1. Админка → **Настройки** → раздел **Интеграция с Битрикс24**.
2. Включите «Включить интеграцию».
3. Вставьте URL вебхука.
4. Нажмите **«Проверить подключение»** — должно появиться имя пользователя.
5. (Опционально) укажите **ID ответственного** за лиды.
6. Сохраните.

После этого каждая заявка с сайта будет создавать лид (`crm.lead.add`) с полями:
имя, телефон, e-mail, сумма (₽), состав заказа в комментарии, источник «Сайт».

### Что если Битрикс24 недоступен
Заявка всё равно сохраняется в БД со статусом `FAILED`. В админке (**Заявки → карточка**)
есть кнопка **«Отправить в Битрикс24»** для повторной отправки.

## 2. Онлайн-чат (Открытые линии)
1. Битрикс24 → **CRM** → **Контакт-центр** → **Открытые линии** / **Виджет на сайт**.
2. Настройте виджет и скопируйте его **код вставки** (`<script>…</script>`).
3. Админка → **Настройки** → **Код виджета онлайн-чата** → вставьте код → сохраните.
4. При включённой интеграции виджет автоматически появится на всех страницах сайта.

## Технические детали
- Код интеграции: `src/lib/bitrix.ts`.
- Метод проверки: `profile`. Метод создания лида: `crm.lead.add`.
- Телефон нормализуется в формат `+7XXXXXXXXXX`.
- Статусы синхронизации: `PENDING | SYNCED | FAILED | DISABLED`.
